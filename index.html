Technical Details

How the Intelligence Works

🎬 Phase 1: Video Analysis & Segmentation

TwelveLabs API performs deep visual understanding of cooking videos, extracting meaningful segments based on:

• Scene Detection
• Speech Recognition
• Object Recognition
• Logo Detection
• Action Identification
• Text Extraction

🧠 Phase 2: LLM-Powered Entity Extraction

OpenAI's structured outputs API intelligently processes video segments to extract and structure:

• Ingredients & Substitutes
• Equipment Used
• Nutritional Claims
• Health Benefits
• Cooking Techniques
• Storage Methods

📊 Phase 3: Knowledge Graph Construction

Neo4j database automatically deduplicates and links entities across videos:

• Entity Deduplication
• Cross-Video Linking
• Relationship Mapping
• Real-time Updates
• Contradiction Detection
• Semantic Indexing

🔍 Phase 4: Semantic Search & Query

Ask natural language questions and get precise answers powered by graph traversal:

💬 "What ingredients are used in high-protein recipes?"

💬 "Which videos contain low-carb meal prep ideas?"

💬 "Show me conflicting nutritional claims about quinoa"

Questions

Frequently Asked Questions

What video formats are supported? v
We support YouTube videos, Vimeo links, and local file uploads (MP4, MOV, WebM). Videos are processed in real-time.
How long does it take to analyze a video? v
A typical 10-minute meal prep video is analyzed in 30-60 seconds. The time depends on video length and complexity.
Can I export the data? v
Yes! You can export extracted entities as JSON, query results as CSV, or access everything via our REST API.
Is my data private? v
All video data is processed securely. We don't store raw videos, only extracted metadata in our encrypted database.
Can I integrate this with my own app? v
Absolutely! We provide a complete REST API with authentication, rate limiting, and webhook support for integration.
What about accuracy of AI extraction? v
Our system achieves 95%+ accuracy on entity extraction. All claims and nutritional information are flagged for verification.
